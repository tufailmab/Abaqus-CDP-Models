  <h1>Abaqus-CDP-Models</h1>

  <p>This project provides a collection of <strong>Concrete Damage Plasticity (CDP)</strong> material models for use in <strong>Abaqus</strong>. It is ideal for engineers and researchers who want to simulate nonlinear concrete behavior, including cracking in tension and crushing in compression, using ready-to-use material definitions.</p>

  <h2>Features</h2>
  <ul>
    <li><strong>Material Library:</strong> Collection of CDP models for different concrete grades. </li>
    <li><strong>Complete Definitions:</strong> Includes elastic properties, compression hardening, and tension softening data.</li>
    <li><strong>Consistent Format:</strong> Well-structured material data for easy implementation in Abaqus.</li>
    <li><strong>Easy Expansion:</strong> Add new materials or calibrated datasets as needed.</li>
  </ul>

  <h2>Usage Instructions</h2>
  <ol>
    <li>Open your model in Abaqus.</li>
    <li>Define material properties using the provided CDP parameters.</li>
    <li>Run your simulation with the selected concrete model.</li>
  </ol>

  <h2>Requirements</h2>
  <ul>
    <li>Abaqus (Finite Element Analysis software)</li>
    <li>Basic understanding of Concrete Damage Plasticity (CDP)</li>
  </ul>
